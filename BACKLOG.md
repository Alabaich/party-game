# Бэклог

Ідеї й домовленості з підготовки Halloween-вечірки Prism (30.10.2026).
Порядок усередині розділів — від важливого до менш важливого.

## 1. Бізнес-модель

### Головний принцип (рішення власника)
**Для людей — усе хороше безкоштовно. Платять лише компанії.**
Людина святкує день народження — ми раді допомогти, без доплат за кожну дрібницю.
Ніколи не забираємо в людей те, що робить свято класним:
- усі анімації й теми (тиква і т.д.) — **безкоштовно для всіх, назавжди**;
- усі події, шаблони свят і набори завдань — **безкоштовно для всіх**;
- **не чарджити за анімацію тикви. Ніколи.**

Компанія (property management, корпоратив, бренд) — **розкашелься**: брендинг і бізнес-функції.

### Рівні
| | Люди (безкоштовно) | Business |
|---|---|---|
| Гра, анімації, теми, набори завдань | усе | усе |
| Гравців | щедрий ліміт від зловживань (не як paywall) | без ліміту |
| Галерея | 30 днів (див. «Зберігання фото») | довге зберігання, оригінали |
| Значок «Made with Party Quest» | маленький, як подяка | немає |
| Логотипи/брендинг | — | ✓ |
| Модерація, CSV згод, звіт після події, кольори й шрифт клієнта | — | ✓ |
| Ціна (гіпотеза) | $0 | $10 за брендинг події або підписка |

### Зберігання фото
- [ ] Безкоштовно 30 днів відкритої галереї.
- [ ] Лічильник у галереї: «Gallery open for 12 more days — save your favourites».
- [ ] Нагадування на email за 7 днів і за 1 день до закриття (+ «Host your own game — free»).
- [ ] «Download all (ZIP)» для організатора і гостей.
- [ ] Продовження **за терміном, не «назавжди»**: $5 → ще рік, потім знову продовжити або скачати.
      «Forever» не продаємо: це зобов'язання без кінця, а ціни сховища можуть зрости.
- [ ] Підписка для активних організаторів (~$3/міс або ~$25/рік) на всі їхні події.
- [ ] Після закриття: лист «закривається через 7 днів, скачай архів», потім видалення.
- [ ] Через 30 днів стискати до веб-якості (фото 1–2 МБ, відео 720p): обсяг падає в 5–10 разів,
      рік зберігання коштує центи. Оригінали — лише до кінця 30 днів (ZIP) або в Business.
- Нотатки: Stripe бере ~$0.30 + 2.9%, тому платежі від $5. R2 ≈ $0.015/ГБ/міс, трафік безкоштовний;
  вечірка ≈ 1–3 ГБ.

### Що платять компанії
- [ ] **Брендинг: $10 за подію** (скільки завгодно логотипів + без значка Party Quest).
- [ ] **Business-підписка: брендинг без обмежень** на всі події та логотипи; модерація, CSV згод,
      звіт після події, кольори й шрифт клієнта, довге зберігання.
      Продавати як «більше 3–4 подій на рік — підписка вигідніша».
- [ ] Пізніше: генерація пакета завдань під опис події — безкоштовно для людей теж.
- ~~Платні анімації, теми, пакети завдань для людей~~ — **НЕ робимо** (див. головний принцип).

## 2. Вихід на ринок

- [ ] Перший сегмент: **property management / житлові комплекси** (бюджет на resident engagement,
      регулярні свята). Потім корпоративні HR-івенти, весілля.
- [ ] Кейс Prism: фото екрана з тиквою і людьми, цифри (гравці, фото, знайомства), цитата менеджера.
- [ ] Вірусний цикл: екран переможця, галерея і лист з фото → «Host your own game — free».
- [ ] Не будувати SaaS одразу: 5 реальних подій (Дівалі, Різдво в Prism, знайомі),
      після кожної — один найважливіший апгрейд. Онбординг і оплата — коли хтось сторонній заплатить.
- Конкуренти: Goosechase, Scavify та схожі. Відмінності: без встановлення (QR → ім'я → гра),
  великий екран як шоу, механіка знайомств (пари, «знайди Priya з 80 Bond»).

## 3. SaaS-функції

- [ ] Самостійна реєстрація організатора, створення гри з шаблону за 5 хв, оплата (Stripe).
- [ ] Бібліотека шаблонів свят: Halloween, Diwali, Christmas, Summer BBQ, Move-in day
      (завдання, тема, текст згоди).
- [ ] Тема Diwali з власною анімацією (дія/лампа) — зараз анімація лише для Halloween.
- [ ] Підсумок після події для організатора: гравці, фото, знайомства, топ-фото, архів для маркетингу.
- [ ] Скидання пароля і OTP для адмінів (потрібен SMTP).
- [ ] Альтернативні режими виграшу: за кількістю знайомств або розіграш серед усіх, хто виконав ≥3 завдання
      (щоб старші й повільніші мали шанс).

## 4. Безпека фото й людей

Зроблено до вечірки: згода з версіями й таймстампами, «Host only» галерея, модерація (Hide),
правило «Ask before you snap…» на телефоні й ТВ, одноразове вікно «Before you snap»,
завдання фотографують лише гравців.

- [ ] Передмодерація: фото на ТВ лише після «Approve» модератора (перемикач у налаштуваннях гри).
- [ ] Кнопка «Report» на фото (для гравців).
- [ ] Галочка «на фото є дитина» при завантаженні → тільки ведучому.
- [ ] Згода по людині: «не публікувати моє обличчя в маркетингу» + маркетинговий експорт без таких людей.
- [ ] Приватний бакет + тимчасові посилання (5–10 хв) замість публічних URL.
- [ ] Справжня ідентичність гравця: секретний токен на пристрої замість UUID у посиланні;
      «отримати мої фото» через email-код після гри.
- [ ] «Мої фото» = де я учасник (пари, «знайди», позначки на групових фото).
- [ ] Автоматичне розпізнавання облич/віку як додатковий фільтр (далеко).
- [ ] Обмеження частоти запитів (вгадування кодів ігор, реєстрації).

## 5. Ігрова механіка

- [ ] «Can't find them → give me someone else»: заміна цілі на гравця, активного останні 15–20 хв.
- [ ] «I'm heading home»: гравця прибирають з цілей у інших.
- [ ] Опційна селфі-аватарка при реєстрації, показується в «👋 Find Priya».
- [ ] Режим «Staff targets» для корпоративних подій: цілі/пари лише з персоналу (адмін додає список з фото).
- [ ] Парні завдання для новеньких, не ламаючи фінішу тих, хто вже закінчив.
